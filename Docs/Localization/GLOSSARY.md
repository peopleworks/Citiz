# Glossary

Terms that must be translated consistently across a language pack, with the Spanish rendering as the
worked example. Language maintainers extend this file with their language's column.

## Do not translate

`Citiz`, `USCIS`, `Form N-400` / `N-400`, `65/20`, the official test names (`2008 Civics Test`,
`2025 Civics Test`), question ids (`2025-002`), and every official question and accepted answer.

## Register

Address the learner directly and warmly (Spanish: *tú*). Short sentences. No legal or technical
jargon where a plain word exists. Never promise an outcome.
